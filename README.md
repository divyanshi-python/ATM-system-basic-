💳 ATM System Mini Project (Python)

📌 Project Overview

This is a basic ATM system mini project created using Python.
It simulates simple ATM operations like balance checking, deposit, and withdrawal using conditional statements and user input.

This project helps in understanding real-life application of Python programming and logic building.

🚀 Features

- Secure PIN verification
- Check account balance
- Deposit money
- Withdraw money
- Simple user interaction

🧠 Concepts Used

- Python input/output
- If-else conditions
- Nested conditions
- Variables and arithmetic operations
- Basic real-life logic implementation

💻 Technologies Used

- Python (Beginner Level)

🎯 Purpose of Project

This project is created for practice and to strengthen Python logic building skills.
It also helps in building a beginner-friendly GitHub portfolio for placements and interviews.

▶️ How to Run

1. Open the file in any Python editor (VS Code, IDLE, etc.)
2. Run the program
3. Enter PIN to access ATM features
4. Choose option to check balance, deposit, or withdraw

📈 Future Improvements

- Multiple users system
- Loop-based ATM menu
- PIN retry system
- GUI version using Python
